# Дизайн-референсы для UI-чанков

> Применимо к Chunks 4, 5, 6, 9, 10, 11, 13.

## Принцип

**Перед началом любого UI-чанка** Claude Code обязан запросить у пользователя дизайн-референсы. Без референсов — UI получится "как стандартно у Claude" — серый, симметричный, бренд-обезличенный. С референсами — UI становится продуманным и узнаваемым.

## Что запрашивать

Для каждого UI-чанка задать пользователю эти 4 вопроса:

1. **Скриншоты сайтов** — есть ли референсы по стилю (цвета, типографика, layout)?
2. **Figma/Sketch макеты** — есть ли готовые макеты конкретных экранов?
3. **Конкретные блоки** — "вот этот компонент с сайта X похож на нужное"
4. **UX-пожелания**:
   - Что должно быть на одном экране, что в модалке/drawer?
   - Тема: light, dark, или toggle?
   - Density: compact (Linear-style) или comfortable (Notion-style)?
   - Целевые устройства: только desktop, mobile-first, или равноправно?

## Если референсов нет

Использовать `AskUserQuestion` с **preview** (ASCII-mockups в options) для предложения 2-3 вариантов:

```
Option 1 (Compact, Linear-style):
┌─────────────────────────────────┐
│ Дашборд               👤 Иван   │
├─────────────────────────────────┤
│ ▸ Задания (4)                   │
│ ▸ Ученики (12)                  │
│ ▸ Аналитика                     │
└─────────────────────────────────┘

Option 2 (Spacious, Notion-style):
╔═════════════════════════════════╗
║                                 ║
║   Привет, Иван 👋               ║
║                                 ║
║   Сегодня:                      ║
║     • 3 непроверенных работы    ║
║     • 2 занятия                 ║
║                                 ║
╚═════════════════════════════════╝
```

Пользователь выбирает → Claude Code делает по выбранному варианту.

## Хорошие референсы для AICheck

Я могу предложить эти проверенные источники если у пользователя нет своих:

- **Linear** (linear.app) — чистый, плотный, продуктивный UI для рабочих инструментов
- **Notion** (notion.so) — гибкий layout, документы, таблицы
- **Vercel Dashboard** — современный enterprise-стиль
- **Cal.com** — публичная страница, расписание
- **Stripe Dashboard** — графики, метрики, фильтры
- **Gradescope** — side-by-side review домашек (зарубежный референс концепции)
- **Profi.ru / Тетрика** — маркетплейс репетиторов (русский контекст)
- **shadcn/ui** (ui.shadcn.com) — стандартные компоненты, на которых строится UI

## Почему это важно

- UI без референсов = "ChatGPT-стиль" — узнаваемо AI, отталкивает пользователей
- Style contract для AI-комментариев работает только если UX тоже не AI-сгенерированный
- Дизайн-система задаётся на старте, иначе придётся переделывать

## Чек-лист перед стартом UI-чанка

- [ ] Запросил у пользователя референсы (через AskUserQuestion)
- [ ] Получил конкретные ссылки или ASCII-варианты выбраны
- [ ] Уточнил тему (light/dark) и density
- [ ] Уточнил целевое устройство
- [ ] Зафиксировал в commit-сообщении первого UI-коммита: "UI follows references: [...]"
