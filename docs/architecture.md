## Принципы

1. **Изоляция PII.** Все ПДн (ФИО, email, телефон) хранятся только в PostgreSQL на VPS в РФ. AI-сервисы получают только `pseudo_id` (UUID) + контент работы. Анонимизация — обязательный layer (`apps/api/app/services/ai/anonymizer.py`).

2. **Async везде.** FastAPI async + SQLAlchemy 2.0 async + aiohttp/httpx + asyncpg. Никаких блокирующих вызовов в HTTP-handlers.

3. **Тяжёлые задачи — в Celery.** AI-проверка занимает 15-45 секунд. Это не помещается в HTTP request → Celery + retry-логика.

4. **Двухуровневый AI-анализ.** GPT-5.4 mini для быстрого извлечения ошибок (structured output), GPT-5.4 для качественной генерации финального комментария. Claude Sonnet — fallback.

5. **Pseudonymous students.** Ученики создаются по псевдониму (без ФИО). Это обходит требование отдельного письменного согласия родителей по 152-ФЗ и повышает конверсию.

6. **Style contract.** Все AI-комментарии проходят через жёсткий стилевой контракт (без AI-маркеров типа "Молодец что попробовал"). Snapshot-тесты обязательны.

## Безопасность

- TLS (Let's Encrypt) на production-домене
- Rate limiting на /auth (10 r/s) и /api (100 r/s)
- CSP headers, защита от XSS
- JWT access (15 min) + refresh (30 d), single-use refresh tokens
- Все секреты только в env vars
- pg_dump каждые 6 часов → S3
- 152-ФЗ: ПДн на серверах в РФ, анонимизация перед AI-вызовами
