# chunk-status

Обновляет статус чанка в `docs/STATUS.md`.

## Когда использовать

- После прохождения всех критериев готовности чанка из `docs/plan.md`
- Перед merge feature-branch в main
- Когда пользователь просит "обнови статус", "отметь чанк N как готовый"

## Что делает

1. Читает текущую ветку (`git rev-parse --abbrev-ref HEAD`) и парсит номер чанка из `chunk/NN-name`
2. Читает `docs/STATUS.md`
3. Находит строку соответствующего чанка
4. Обновляет:
   - Статус: в работе → готово
   - Дата завершения: текущая дата (YYYY-MM-DD)
   - PR #: спрашивает у пользователя, если не указан
5. Записывает обратно
6. Делает коммит: `Chunk N: complete — обновлён STATUS`

## Параметры

- `chunk_number` (опционально) — если не указан, парсится из текущей ветки
- `pr_number` (опционально) — номер PR на GitHub

## Пример

Пользователь: "Чанк 7 готов, PR #15"

Skill:
1. Читает STATUS.md
2. Меняет строку Chunk 7: статус готов, дата завершения = сегодня, PR # = 15
3. Записывает
4. Коммит + push на ветку

## Файлы

- `docs/STATUS.md` — статус-таблица
- `docs/plan.md` — план для проверки критериев готовности
