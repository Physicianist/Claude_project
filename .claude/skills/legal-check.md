# legal-check

Проверяет юридическое соответствие проекта требованиям РФ (152-ФЗ, согласие пользователей).

## Когда использовать

- Перед каждым production deploy (Chunk 14)
- После изменений в `docs/legal/`
- После изменений в `apps/web/app/legal/{privacy,terms,cookies}/page.tsx`
- При смене юр. формы (самозанятый → ИП)
- При расширении сбора данных (новые поля в формах регистрации)

## Что проверяет

### 1. Наличие документов

- [ ] `docs/legal/privacy-policy.md` существует и не пуст
- [ ] `docs/legal/terms-of-service.md` существует и не пуст
- [ ] `docs/legal/cookie-notice.md` существует и не пуст
- [ ] Если используется согласие родителя: `docs/legal/parent-consent-template.md` существует

### 2. Доступность страниц на сайте

```bash
curl -i http://localhost:3000/legal/privacy
curl -i http://localhost:3000/legal/terms
curl -i http://localhost:3000/legal/cookies
```

Все должны вернуть 200, не 404.

### 3. Ссылки в footer

- Footer на главной странице должен содержать видимые ссылки на все 3 юр. страницы

### 4. Регистрация в РКН

- В `docs/legal/rkn-notification.md` должен быть номер уведомления (после подачи)
- Для production — проверить наличие в реестре операторов ПДн

### 5. Актуальность даты

- Дата "последнее обновление" в политике — не старше 12 месяцев

### 6. Соответствие 152-ФЗ (с 30.05.2025)

Privacy policy должна содержать:
- [ ] Категории субъектов (ФИО, email, phone, демография)
- [ ] Цели обработки
- [ ] Правовые основания
- [ ] Перечень действий с ПДн
- [ ] Сроки хранения
- [ ] Права субъекта (отзыв, доступ, удаление)
- [ ] Контакты оператора и DPO (если есть)

### 7. Согласия на обработку

- [ ] Регистрационная форма содержит чекбокс согласия с привязкой к актуальной версии политики
- [ ] При добавлении email родителя — отдельный чекбокс согласия родителя на обработку ПДн ребёнка

### 8. Cookie consent

- [ ] Баннер cookies показывается при первом визите
- [ ] Различает технические и аналитические cookies
- [ ] Можно отказаться от не-необходимых

## Что делает

1. Запускает все проверки выше
2. Возвращает отчёт:
   - ✓ Прошло
   - ✗ Не прошло (с конкретным указанием)
3. Если есть критические провалы — блокирует production deploy

## Файлы

- `docs/legal/` — все юридические шаблоны
- `apps/web/app/legal/` — рендер юр. страниц
- `apps/web/components/footer.tsx` — ссылки в footer
- `apps/web/components/cookie-banner.tsx` — баннер cookies
